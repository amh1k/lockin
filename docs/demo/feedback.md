# Tester feedback record

No tester session has been recorded yet. Do not fill in answers from memory or infer interest from a demo. Ask one willing person to use the unpacked build and record consent before retaining notes. Remove names, account identifiers, goals, and page URLs from any shared version.

## Short test script

1. Ask the tester to follow the README setup and tell you where they get stuck. Do not take over unless requested.
2. Ask them to enter one real work goal and start a session.
3. Have them open one page they consider useful and one page they consider distracting on a supported site. Record the actual LockIn outcomes and latency; ask whether the short reason makes sense.
4. If a page is blocked, ask them to find and use the page override, then end the session.
5. Ask: “Would you pay for something like this? What would need to improve first?” Record their words accurately and separately from your interpretation.
